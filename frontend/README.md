# PumpInsight

Статический прототип аналитики насосного оборудования: загрузка JSON, валидация по схеме 1.0, расчёт метрик наработки, визуализация давления и оборотов, панель из 10 диагностических гипотез. Все вычисления выполняются локально в браузере без отправки данных на сервер.

## Запуск
Нужен Node.js 18 или новее:

```bash
npm install
npm run dev
```

Открыть http://localhost:5173. Порт задаётся в vite.config.ts.

## Файлы
- `src/App.tsx` — основной интерфейс: загрузка файла, графики, метрики, гипотезы
- `src/analyzer.ts` — валидация JSON, классификация интервалов, расчёт метрик, проверка гипотез
- `src/analysis-view.ts` — вспомогательные функции для отображения данных
- `index.html` — входная точка приложения
- `vite.config.ts` — конфигурация сборщика Vite, прокси /api на бэкенд (порт 8000)
- `data/` — тестовые файлы (01_small.json … 07_single_point.json, format_errors/08–10.json)

## Обновление данных
Для работы с новыми JSON-файлами достаточно поместить их в папку data/ и загрузить через интерфейс. Python не требуется — все расчёты выполняются в браузере.

## Ограничения
Это клиентский прототип без подключения к бэкенду. Анализ выполняется по тем же правилам, что и в спецификации (max_interval_s = 1.5 с, приоритет: пропуск → недостоверность → работа/остановка), но результаты не сохраняются в output/ и не генерируют matplotlib-графики. Синтетические данные (synthetic: true) помечаются предупреждением — выводы относятся только к учебному набору.

## Состав репозитория
Коммитить только исходный код фронтенда (src/, index.html, конфиги), тестовые данные (data/) и документацию. Не включать node_modules/, dist/, .env-файлы, скриншоты и временные файлы. Перед коммитом проверять состав изменений; .gitignore не обходить принудительным добавлением.
