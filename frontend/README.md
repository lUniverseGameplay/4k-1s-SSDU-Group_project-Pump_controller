# PumpInsight

Веб-приложение для аналитики насосного оборудования: загрузка JSON-файлов, проверка данных по схеме 1.0, расчёт метрик наработки и времени остановок, определение пропусков и недостоверных измерений, визуализация давления и оборотов, панель из 10 диагностических гипотез.

Вычисления выполняются на Python-сервере. Результаты анализа, графики и диагностические гипотезы сохраняются в `output/` и доступны через API.

## Запуск

Необходимы Python, Node.js и npm.

Сначала запустить сервер:

```bash
pip install .
python -m uvicorn app.main:app --reload --port 8000
```

Затем в отдельном терминале:

```bash
cd frontend
npm install
npm run dev
```

Открыть http://localhost:8443.

Документация API: http://127.0.0.1:8000/docs.

Для проверки production-сборки:

```bash
cd frontend
npm run build
```

## Файлы

- `app/main.py` — настройки и запуск FastAPI.
- `app/endpoints.py` — API-запросы и обработчики.
- `app/core.py` — проверка данных, расчёт метрик и диагностических гипотез.
- `app/visualization.py` — построение графиков.
- `app/output_manager.py` — сохранение результатов анализа.
- `frontend/src/App.tsx` — основной интерфейс: загрузка файлов, графики, метрики и гипотезы.
- `frontend/src/api.ts` — отправка запросов и получение результатов анализа.
- `frontend/src/analyzer.ts` — типы данных и преобразование результатов для отображения.
- `frontend/src/analysis-view.ts` — вспомогательные функции отображения, фильтрации и обработки интервалов.
- `frontend/index.html` — входная точка приложения.
- `frontend/vite.config.ts` — конфигурация Vite и прокси `/api` на сервер.

## Обработка данных

Для анализа достаточно загрузить JSON-файл через интерфейс приложения.

Файл отправляется на сервер через `POST /api/analyze`. После проверки и обработки данных возвращаются:

- количество измерений и продолжительность записи;
- время работы и остановок оборудования;
- время пропусков и недостоверных измерений;
- распределение по режимам работы;
- результаты 10 диагностических гипотез;
- PNG-график давления и оборотов;
- JSON-файлы отдельных гипотез.

Результаты доступны через API и сохраняются в папке `output/`.

## Ограничения

- Для выполнения анализа требуется запущенный сервер.
- Поддерживается формат входных данных со схемой 1.0.
- Интерполяция и экстраполяция измерений не выполняются.
- Максимально допустимый интервал между измерениями — 1,5 секунды.
- При классификации интервалов приоритет имеют: пропуск → недостоверность → работа или остановка.
- Синтетические данные (`synthetic: true`) помечаются в интерфейсе как учебные.
- Для сохранения результатов после перезапусков на Render необходимо настроить постоянное файловое хранилище.

## Состав репозитория

Коммитить исходный код, конфигурационные файлы, необходимые тесты и документацию.

Не включать:

- `node_modules/`
- `frontend/dist/`
- `.env` и другие файлы с секретами.
- `.venv/` и `venv/`
- `__pycache__/`
- временные файлы и результаты анализа из `output/`.

Перед коммитом проверять состав изменений командой `git status`. Для публикации обновлений использовать `git push` в подключённую к Render ветку репозитория.
